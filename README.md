# Mobile-Optimized Multiplayer Shooter

A fast-paced, real-time multiplayer shooting game built with Node.js, Socket.io, and HTML5 Canvas. This project is specifically designed for mobile devices featuring virtual joysticks for movement and aiming.

## Features

-   **Multiplayer Gameplay**: Real-time synchronization using Socket.io.
-   **Mobile-First Controls**: 
    -   **Left Joystick**: Move your player in any direction.
    -   **Right Joystick**: Aim and automatically fire.
-   **Responsive Canvas**: Automatically scales to fit any screen size or orientation.
-   **Server-Side Physics**: Bullet collision and player movement are handled on the server to prevent cheating.
-   **Leaderboard**: Track top scores in real-time.

## Prerequisites

-   [Node.js](https://nodejs.org/) (v14 or higher recommended)
-   npm (comes with Node.js)
